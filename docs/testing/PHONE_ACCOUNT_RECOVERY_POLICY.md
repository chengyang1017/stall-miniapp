# 手机号换绑与号码回收：账号恢复规则

本阶段仅提供纯策略判断函数 `backend/src/customerPhoneRecoveryPolicy.mjs` 和单元测试；不暴露 API、不创建短信服务，也不允许无凭据执行换绑。

1. 手机号不是永久身份。登录、订单、会员资料始终属于 `customer_accounts.id`。
2. 若新手机号已绑定别的永久账号，进入人工审核，不自动合并或转移任何订单。
3. 只有新号码短信/微信手机号证明不够：必须另外证明原账号所有权，例如此前已绑定的微信身份或独立安全凭据。
4. 失去旧手机号且没有其他安全身份时，不能仅依赖拿到新号就恢复账号；需人工恢复流程。
5. 所有正常换绑仍需要近期服务端 step-up 证明，再调用事务型 `rotateVerifiedPhone`。内部布尔参数不是可信凭据，不能直接从前端传入。
6. 换绑成功后未来应撤销旧手机号的独立登录身份与会话、更新持久绑定、写审计记录并通知用户；这些尚未实现，所以换绑入口保持关闭。

测试：`node --test backend/tests/customer-phone-recovery-policy.test.mjs`。本文件不是上线批准。
